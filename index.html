?? Claude CLI Student Guide

Complete guide to installing and using the Claude AI assistant in your terminal.

Step 1: Install Node.js

The Claude CLI requires Node.js. Check if you have it installed:

node --version

If you see an error, download it from nodejs.org.

Step 2: Install Claude CLI

Run this command to install Claude globally on your system:

npm install -g @anthropic-ai/claude-cli

Step 3: Login & Chat

Once installed, you can start talking to Claude immediately!

claude
